Version 1 was trained only on what the generator's author imagined. A second agent then wrote 120 requests the way real people type, without seeing the generator. Reading those showed the gaps: long URLs with %20, +, @, ( ) and #, terse forms like "links only: site.com" or "text + title", rambling three-sentence requests, and requests that contain a URL but are not scraping ("is takealot.com down?"). Version 2 added those kinds of patterns in general form (not the dev sentences themselves), raised the request limit from 150 to 280 characters and the context from 256 to 512. Version 2 still lost most of its dev and blind points on one thing: copying an unusual URL letter for letter. It wrote common words it knew in place of odd path parts, ids and hashes. Version 3 adds URL paths made only of copy-only tokens (upper-case ids, hex hashes, long slugs, mixed case, query strings) and two-part country domains such as .co.za and .gov.uk, so the model must learn to copy instead of to recall.
